# Zoya AI Voice Assistant - Windows Desktop App

This package wraps the existing Zoya React/Vite app in Electron. The existing UI and features are kept as-is.

## Easiest method
1. Extract this ZIP completely.
2. Open the `zoya-src` folder.
3. Double-click `build-windows.bat`.
4. Wait for `BUILD SUCCESSFUL!`.
5. The `release` folder will open automatically.
6. Run `Zoya-AI-Voice-Assistant-Setup-0.0.0.exe`.

Requirements: Windows 10/11 and Node.js LTS installed. The batch file checks for Node/npm and installs project dependencies automatically.
